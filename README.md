# stduse

My personal Fortran "standard library". Just a bunch of code in one big module so I can drag it around easily when working on different things (maybe I will switch to submodules when I feel like dragging multiple files around).

stduse just uses plain Fortran (my original standard library).
stdlinalg uses BLAS and LAPACK (and stduse).

Note that this is very much under development (just take what you might need or be risky and take everything).
As of now I have just ran through a bunch of my code, found what pieces might fit, and pasted them here.
It will be cleaned up.
